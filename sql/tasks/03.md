Задание 3. Группировка и подсчёт
================================

Что нужно знать
---------------
GROUP BY собирает строки в группы, а агрегатные функции считают значение
на каждую группу. COUNT(*) считает строки в группе.

Колонке можно дать имя через AS и использовать его в ORDER BY.

Пример, число клиентов по городам, можно запустить:

    SELECT city, COUNT(*) AS people
    FROM customers
    GROUP BY city
    ORDER BY people DESC, city;

Условие
-------
Посчитать число заказов в каждом статусе.

- Таблица: orders
- Колонки результата: status, orders_count
- Сортировка: по orders_count по убыванию, при равенстве по status по алфавиту
