Задание 9. Финальное: задача 1 из теста
=======================================

Заказы по городам. На тесте: 4 минуты, 15 баллов.

Посчитать по каждому городу число заказов за 2026 год и число разных клиентов,
которые эти заказы сделали.

- Город клиента — customers.city
- Заказы со статусом cancelled не учитываются
- Год определяется по orders.created_at
- Колонки результата: city, orders_count, customers_count
- Сортировка по orders_count по убыванию, при равенстве — по city по алфавиту
