Задание 5. Соединение таблиц
============================

Что нужно знать
---------------
JOIN соединяет строки двух таблиц по условию в ON. В результат попадают только
пары, для которых условие выполнено.

Если колонка с одним именем есть в обеих таблицах (например, id или name),
её нужно указывать через алиас таблицы. Алиас также нужен, чтобы дать колонке
результата понятное имя.

Пример, можно запустить:

    SELECT i.id AS item_id, p.name AS product_name, i.qty
    FROM order_items i
    JOIN products p ON p.id = i.product_id
    WHERE i.qty = 4
    ORDER BY i.id;

Условие
-------
Вывести заказы клиентов из города Казань за апрель, май и июнь 2025 года.
Статус заказа не важен.

- Таблицы: orders, customers
- Колонки результата: order_id, customer_name, created_at
- Сортировка: по created_at по возрастанию, при равенстве по order_id по возрастанию
