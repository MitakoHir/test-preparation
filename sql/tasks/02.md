Задание 2. Статусы и диапазон дат
=================================

Что нужно знать
---------------
Условия объединяются через AND. Оператор <> означает «не равно».

created_at хранит не только дату, но и время. Поэтому для периода удобнее
полуоткрытый диапазон: начало включаем, а начало следующего периода нет.
Так в выборку попадёт весь последний день и ничего лишнего.

Пример, клиенты, зарегистрированные в январе 2023, можно запустить:

    SELECT id, name, registered_at
    FROM customers
    WHERE registered_at >= '2023-01-01'
      AND registered_at <  '2023-02-01'
    ORDER BY registered_at, id;

Попробуй сам: чему равно '2026-03-31'::timestamp? Попадёт ли заказ,
созданный 31 марта в 18:30, в BETWEEN '2026-03-01' AND '2026-03-31'?

Условие
-------
Вывести заказы за март 2026 года, кроме отменённых.

- Таблица: orders
- Колонки результата: id, created_at, status
- Отменённый заказ: status = 'cancelled'
- Сортировка: по created_at по возрастанию, при равенстве по id по возрастанию
