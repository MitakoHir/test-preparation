Задание 4. Строки и разные значения
===================================

Что нужно знать
---------------
Эти три выражения считают разное:

    COUNT(*)            все строки группы
    COUNT(col)          строки, где col не NULL
    COUNT(DISTINCT col) разные значения col, без учёта NULL

Пример, можно запустить и сравнить числа:

    SELECT COUNT(*) AS all_rows,
           COUNT(product_id) AS with_product,
           COUNT(DISTINCT product_id) AS different_products
    FROM order_items;

Условие
-------
По каждому статусу посчитать число заказов и число разных клиентов,
которые их сделали. Заказы без клиента (customer_id IS NULL) считаются
заказами, но клиента у них нет.

- Таблица: orders
- Колонки результата: status, orders_count, customers_count
- Сортировка: по orders_count по убыванию, при равенстве по status по алфавиту
