Задание 1. Выборка и сортировка
===============================

Что нужно знать
---------------
SELECT выбирает колонки, WHERE отбирает строки, ORDER BY задаёт порядок.
Направление сортировки указывается для каждой колонки отдельно:
в ORDER BY a DESC, b колонка a идёт по убыванию, а b по возрастанию.

Пример, можно запустить:

    SELECT id, name, registered_at
    FROM customers
    WHERE city = 'Тула'
    ORDER BY registered_at DESC, name;

Условие
-------
Вывести товары дороже 5000.

- Таблица: products
- Колонки результата: id, name, price
- Сортировка: по price по убыванию, при равной цене по name по алфавиту
