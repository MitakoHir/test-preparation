Задание 8. Найти то, чего нет
=============================

Что нужно знать
---------------
«Нет ни одной связанной строки» в SQL записывается так называемым анти-джойном.
Два надёжных способа:

- NOT EXISTS (подзапрос): подзапрос проверяет наличие связанной строки;
- LEFT JOIN и проверка, что у правой таблицы пустой первичный ключ (IS NULL).

Пример на воображаемых таблицах. Авторы, у которых нет книг:

    SELECT a.id, a.name
    FROM authors a
    WHERE NOT EXISTS (
      SELECT 1 FROM books b WHERE b.author_id = a.id
    );

Осторожно с NOT IN. Запусти оба запроса и сравни:

    SELECT 'нашлось' WHERE 1 NOT IN (2, 3);
    SELECT 'нашлось' WHERE 1 NOT IN (2, 3, NULL);

Если в списке есть NULL, NOT IN никогда не даёт TRUE. В order_items есть
позиции с пустым product_id: это товары, удалённые из каталога.

Условие
-------
Вывести товары, которых нет ни в одной позиции заказа. Заказ в любом статусе,
в том числе отменённый, считается заказом.

- Таблицы: products, order_items
- Колонки результата: id, name
- Сортировка: по id по возрастанию
