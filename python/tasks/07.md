Задание 7. Отладка
==================

Что нужно знать
---------------
Сообщение об ошибке (traceback) читается снизу вверх. Последняя строка называет ошибку,
а строки над ней показывают, где она случилась. Сначала найди строку своего файла.

Менять список во время его перебора опасно. Запусти и посмотри, какой ноль остался:

    numbers = [1, 0, 0, 2]
    for number in numbers:
        if number == 0:
            numbers.remove(number)
    print(numbers)

Присваивание не копирует список. Обе переменные указывают на один и тот же объект:

    first = [1, 2]
    second = first
    second.append(3)
    print(first)

Если функция должна оставить входной список прежним, собирай результат в новый список.

Условие
-------
В файле solutions/task_07.py две функции и два бага. Найди и исправь их. Сигнатуры и
поведение по документации менять нельзя.

- without_zeros возвращает числа без нулей. Переданный список менять нельзя.
- done_share возвращает долю задач с done, равным True, округлённую до 2 знаков.
  Для пустого списка: 0.

Запусти check 7 и начни с чтения сообщений об ошибках.
