Задание 4. Сортировка по двум признакам
=======================================

Что нужно знать
---------------
sorted() возвращает новый список, а list.sort() меняет исходный.

Параметр key задаёт, по какому значению сравнивать элементы. Если key возвращает
кортеж, сравнение идёт сначала по первому элементу, при равенстве по второму.
Чтобы число шло по убыванию, а строка по возрастанию, у числа можно сменить знак:

    words = ["кот", "дом", "слон", "ёж"]

    print(sorted(words, key=len))
    print(sorted(words, key=lambda word: (-len(word), word)))

Попробуй заменить знак минус на reverse=True и сравни порядок слов одинаковой длины.

Условие
-------
Написать функцию rank_players(results).

- results: список кортежей вида ("Анна", 30)
- Вернуть новый список кортежей: по очкам по убыванию, при равных очках по имени
  по алфавиту
- Пустой список на входе: пустой результат
- Входной список менять нельзя
