Задание 8. Финальное: задача 3 из теста
=======================================

Суммы по клиентам. На тесте: 5 минут, 20 баллов.

Выдаётся заготовка: solutions/task_08.py

Требования:

- orders — список словарей вида
  {"customer": "Анна", "amount": 1200.5, "status": "paid"}
- Заказы со статусом "cancelled" не учитываются, все остальные — да
- Вернуть список кортежей (клиент, сумма), сумма округлена до 2 знаков
- Сортировка по сумме по убыванию, при равной сумме — по имени по алфавиту
- Клиент, у которого все заказы отменены, в результат не попадает
- Пустой список на входе — пустой результат

Часть тестов скрыта.
