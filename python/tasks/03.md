Задание 3. Суммы по группам и округление
========================================

Что нужно знать
---------------
Дробные числа хранятся приближённо. Запусти и посмотри на результат:

    print(0.1 + 0.2)
    print(round(0.1 + 0.2, 2))

Округлять удобно один раз, в самом конце, когда сумма уже посчитана. Если округлять
каждое слагаемое, итог может получиться другим:

    print(round(0.004 + 0.004, 2))
    print(round(0.004, 2) + round(0.004, 2))

Строки, которые не должны учитываться, удобно пропускать через continue:

    for number in [1, -2, 3]:
        if number < 0:
            continue
        print(number)

Условие
-------
Написать функцию hours_by_employee(records).

- records: список словарей вида
  {"employee": "Анна", "hours": 7.5, "approved": True}
- Учитываются только записи с approved, равным True
- Вернуть словарь: сотрудник и сумма его часов, округлённая до 2 знаков
- Сотрудник, у которого нет подтверждённых записей, в результат не попадает
- Подтверждённая запись на 0 часов тоже учитывается: такой сотрудник в результате есть
- Пустой список на входе: пустой словарь
- Входной список менять нельзя
