Задание 2. Словарь как счётчик
==============================

Что нужно знать
---------------
Обращение к отсутствующему ключу через d[key] даёт KeyError. Метод d.get(key, 0)
вернёт значение по умолчанию, поэтому счётчик удобно увеличивать так:

    colors = ["red", "blue", "red"]
    counts = {}
    for color in colors:
        counts[color] = counts.get(color, 0) + 1

    print(counts)

Условие
-------
Написать функцию count_by_city(people).

- people: список словарей вида {"name": "Анна", "city": "Тула"}
- Вернуть словарь: город и число людей из этого города
- Люди с одинаковыми именами считаются разными людьми
- Пустой список на входе: пустой словарь
- Входной список менять нельзя
