Задание 1. Список словарей: цикл и условие
==========================================

Что нужно знать
---------------
Список словарей перебирается обычным циклом for, значение берётся по ключу.
Новый список собирается через append или через списковое включение.

Пример, можно запустить в интерпретаторе:

    books = [{"title": "Война и мир", "pages": 1300},
             {"title": "Нос", "pages": 40}]

    long_books = []
    for book in books:
        if book["pages"] > 100:
            long_books.append(book["title"])

    print(long_books)

Условие
-------
Написать функцию passed_names(students, min_score).

- students: список словарей вида {"name": "Анна", "score": 80}
- Вернуть список имён тех, у кого score не меньше min_score
- Порядок имён такой же, как во входном списке
- Пустой список на входе: пустой результат
- Входной список менять нельзя
