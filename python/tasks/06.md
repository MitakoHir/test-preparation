Задание 6. Класс со словарём внутри
===================================

Что нужно знать
---------------
Атрибут, объявленный в теле класса, один на все объекты. Если это список или словарь,
изменения через один объект будут видны в другом. Запусти и посмотри:

    class Bag:
        items = []

        def put(self, item):
            self.items.append(item)

    first = Bag()
    second = Bag()
    first.put("яблоко")
    print(second.items)

Чтобы у каждого объекта были свои данные, создавай их в __init__.

У параметра может быть значение по умолчанию: при вызове его можно не указывать.

    def greet(name, times=1):
        print("Привет, " + name + "! " * times)

Условие
-------
Дописать класс Gradebook (журнал оценок).

- add(student, grade, times=1): записать ученику оценку grade столько раз, сколько
  указано в times
- average(student): средняя оценка ученика, округлённая до 2 знаков
- students(): список учеников, у которых есть оценки, по алфавиту
- Бросить ValueError, если grade не от 1 до 5, если times меньше 1 или если в average
  передан ученик без оценок
- После ошибки журнал остаётся прежним: ученик не должен появиться в students()
- Журналы независимы друг от друга
