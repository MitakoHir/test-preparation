Задание 5. Класс и исключения
=============================

Что нужно знать
---------------
Данные объекта хранятся в self и создаются в __init__: этот метод выполняется при
создании каждого объекта.

Ошибка сообщается через raise. Проверку нужно делать до изменения данных: иначе после
ошибки объект останется в испорченном состоянии.

    class Counter:
        def __init__(self):
            self.value = 0

        def add(self, step):
            if step < 1:
                raise ValueError("шаг должен быть положительным")
            self.value += step

    counter = Counter()
    counter.add(2)
    print(counter.value)
    counter.add(0)

Условие
-------
Дописать класс Wallet (кошелёк).

- deposit(amount): пополнить баланс
- withdraw(amount): снять деньги; снять весь баланс целиком можно
- balance(): вернуть текущий баланс; у нового кошелька он равен 0
- Бросить ValueError, если amount меньше или равен 0 или если снимают больше, чем есть
- После ошибки баланс остаётся прежним
- Кошельки независимы друг от друга
