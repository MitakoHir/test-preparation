# Тренажёр к тесту

Два независимых блока: SQL и Python. В каждом по 10 заданий от простого к сложному, решай по порядку. Последние задания в каждом блоке это задачи из теста.

Нужен только Docker. Первый запуск скачает образ, это займёт пару минут.

Вернуть файл решения к исходному виду можно так: `git checkout -- python/solutions/task_07.py`.

# Блок SQL

Задания 1–8 учат нужным приёмам, задания 9 и 10 это задачи 1 и 2 из теста.

## Запуск

```
docker compose --profile sql run --rm psql
```

Откроется psql, подключённый к учебной базе.

Выход из psql: `\q`. Когда закончил работать, останови базу:

```
docker compose --profile sql down
```

Твои решения в `sql/solutions/` при этом сохранятся.

## Как решать

Открой папку в редакторе, а psql держи в терминале рядом.

1. `\! task 4` покажет условие и короткую теорию.
2. Пробуй запросы прямо в psql, смотри на данные.
3. Запиши итоговый запрос в файл `sql/solutions/04.sql`.
4. `\i solutions/04.sql` выполнит файл, чтобы увидеть результат.
5. `\! check 4` проверит решение.

Если застрял: `\! hint 4`. Подсказка задаёт направление, но не содержит готового запроса.

`\! check` без номера покажет прогресс по всем заданиям.

## Что сообщает проверка

| Сообщение | Что смотреть |
|---|---|
| Колонки не совпадают | имена и порядок колонок, `AS` |
| Неверное число строк | условия отбора, тип соединения, границы дат |
| Значения отличаются | что именно считает агрегат |
| Порядок другой | `ORDER BY`, в том числе второй ключ сортировки |

В решении должен быть один запрос `SELECT`.

## База

База `shop` такая же по устройству, как на тесте: PostgreSQL 16, только чтение, 5 секунд на запрос, не больше 5000 строк в ответе, часовой пояс Europe/Moscow. Таблицы пишутся без префикса схемы.

```
customers    (id, name, city, registered_at)
categories   (id, name)
products     (id, name, category_id, price)
orders       (id, customer_id, created_at, status)
order_items  (id, order_id, product_id, qty, price, discount)
```

Значения `orders.status`: `paid`, `shipped`, `delivered`, `pending`, `cancelled`.

В учебных данных есть гостевые заказы с пустым `customer_id` и позиции с пустым `product_id`. Это сделано намеренно: заметишь, как ведут себя запросы на таких данных.

## Полезные команды psql

```
\dt             список таблиц
\d orders       структура таблицы
\x              включить или выключить вертикальный вывод
\q              выход
```

# Блок Python

Задания 1–7 учат нужным приёмам, задания 8, 9 и 10 это задачи 3, 4 и 5 из теста. Как на тесте: Python 3.12 и только стандартная библиотека. В контейнере нет сети, поэтому сторонние пакеты не поставить.

## Запуск

```
docker compose --profile python run --rm python
```

Откроется терминал внутри контейнера. Выход: `exit`. Останавливать отдельно ничего не нужно.

## Как решать

Открой папку в редакторе, а терминал держи рядом.

1. `task 4` покажет условие и короткую теорию.
2. Пиши решение в файле `python/solutions/task_04.py`, там уже лежит заготовка.
3. `python -i solutions/task_04.py` запустит файл и оставит открытым интерпретатор, чтобы вызвать функцию руками. Выход из него: `exit()`.
4. `check 4` проверит решение.

Если застрял: `hint 4`. Подсказка задаёт направление, но не содержит готового решения.

`check` без номера покажет прогресс по всем заданиям.

## Что сообщает проверка

- **Открытые тесты** лежат в `python/tests/`, их можно читать. При ошибке показывается полное сообщение.
- **Скрытые тесты** проверяют то, что ты мог упустить. В заданиях 1–7 видно название непройденного теста. В заданиях 8–10 видно только их число, как на настоящем тесте.

Скрытые тесты лежат в репозитории в упакованном виде. Распаковать их можно, но тогда ты потеряешь главную тренировку: самому продумывать краевые случаи.
